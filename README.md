# frappe-user-management
A clean, API-first authentication and user management app for the Frappe Framework.

## Features
- Session-based login for React/SPAs
- Clean login API (no Desk response noise)
- Role-based authorization helpers
- Scalable service-layer architecture

## Installation
```bash
bench get-app https://github.com/yourname/frappe-auth-api
bench --site your-site-name install-app auth_api
